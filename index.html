UIU UCAM Evaluation Automator

A lightweight, secure Google Chrome extension designed for United International University (UIU) students to automate course evaluations seamlessly.

  • ⚡ One-Click Automation: Evaluates all enrolled courses automatically.
  • 🎯 Custom Target Grade: Set desired expected grades (A, A-, B+, etc.).
  • 📊 Live Progress Tracker: Visual progress bar and course counter.
  • 🔒 100% Client-Side Privacy: Zero data collection, credentials stored locally only.
