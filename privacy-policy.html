Official Privacy Policy

UIU UCAM Course Evaluation Automator

Last Updated: September 2026  |  Extension Version: 1.0.1  |  Developer: Irfan Haider Abir (Student ID: 0112230474)

1. Overview & Single Purpose

The UIU UCAM Course Evaluation Automator is an open-source productivity browser extension created to streamline and automate the end-of-trimester course evaluation workflow for students of United International University (UIU) on the official university portal (https://ucam.uiu.ac.bd/).

This Privacy Policy outlines how your data is handled when using this extension. We believe in total transparency: the extension operates 100% locally on your computer and does not transmit any information to external servers.

2. Information Collection and Telemetry

🔒 Zero Data Collection Guarantee: The extension does NOT collect, track, log, transmit, sell, or monetize any of your personal data, credentials, browsing activity, or analytics to any remote server or third-party service.

Specifically:

  • No Analytics or Tracking: There are no Google Analytics, telemetry scripts, ads, or third-party tracking libraries included in this extension.
  • No External Server: There is no backend server or database connected to this extension.
  • Direct Communication Only: All network requests initiated by the browser during automation communicate strictly and directly with the official university portal (https://ucam.uiu.ac.bd/).

3. Credentials & Local Data Storage

The extension allows you to optionally save your student credentials to enable seamless login during automation:

  • Optional Storage: If and only if you activate the "Save Login Info" switch, your UIU Student ID and Password are stored locally in your browser's private storage area using Chrome's built-in chrome.storage.local API.
  • Session In-Memory Handling: If the "Save Login Info" switch is turned off, your credentials are held only in temporary memory during the active evaluation run and are wiped immediately once the automation finishes.
  • Local Isolation: Chrome restricts chrome.storage.local to this extension alone; no website or other extension can access this storage.

4. Chrome Permissions Justification

In accordance with Chrome Web Store Minimal Permissions policies, the extension requests only the minimum set of permissions necessary to function:

Permission Purpose & Scope
storage Used exclusively to save user UI preferences (such as selected target grade and the "Remember Me" toggle) and display local activity logs in the popup via chrome.storage.local.
activeTab Used to interact with the active browser tab when the student starts the evaluation process, allowing seamless navigation to evaluation forms.
https://ucam.uiu.ac.bd/* Host permission restricted strictly to the official UIU UCAM domain. Required to interact with the evaluation form elements, submit responses, and display the floating progress badge. The extension cannot execute or read data on any other domain.

5. User Data Control & Deletion

You have complete control over any data stored by the extension at any time:

  • Clear Saved Credentials: Toggle off the "Save Login Info" switch in the extension popup to instantly remove stored credentials from local storage.
  • Clear Activity Logs: Click the "Clear" button in the activity log section of the popup to wipe all logged actions.
  • Full Deletion: Removing or uninstalling the extension from Chrome (chrome://extensions) permanently deletes all extension settings, stored keys, and logs from your device immediately.

6. Third-Party Disclosures & Program Policy Compliance

In strict compliance with the Chrome Web Store Developer Program Policies:

  • We certify that your data is not sold or transferred to any third party.
  • We certify that your data is not used or transferred for purposes unrelated to the extension's core functionality (course evaluation automation).
  • We certify that your data is not used or transferred to determine creditworthiness or for lending purposes.
